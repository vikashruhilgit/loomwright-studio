# Brand kit

The files and rules for showing Loomwright Studio outside the app: a README header, a website, a social card, docs. The rules come from the [brand book](../brand-book.md) and the colours from [`tokens.json`](../tokens.json). This folder only packages them. The owner chose the direction on 2026-11-01 from two rounds of options: the rendered ribbon as the colour mark, the solid band as the one-colour mark, the name in two weights, and the night banner.

Every file here is generated by `python3 app/scripts/brand-kit.py`. It needs numpy, Pillow, `rsvg-convert` and a Chromium; it finds Playwright's headless shell, or you can set `CHROMIUM`. To change anything, change the geometry, the renderer or a token, then re-run the script. Never edit an exported file by hand.

## The mark

The mark is the app icon's ribbon on its own: a band of fine threads run round a rounded triangle with three half-twists, a one-sided Möbius loop. It is not redrawn. The colour mark is the icon's renderer (`app/scripts/icon-render.py`) drawing the ribbon without its tile. The one-colour mark is the same ribbon's outline from the shared geometry (`app/scripts/ribbon_geometry.py`), filled solid. The menu-bar glyph (`MenubarGlyph`) is a separate cut of the same ribbon, tuned for 18pt.

| File | Use |
|---|---|
| `mark/png/loomwright-studio-mark-colour-on-light-{size}.png` | **The mark.** The icon's lit ribbon in deeper indigo so it holds on light grounds |
| `mark/png/loomwright-studio-mark-colour-on-dark-{size}.png` | The mark on dark grounds: the ribbon exactly as on the Dock icon |
| `mark/loomwright-studio-mark-ink.svg` (+ PNGs) | One colour, `ink`: favicons, print, anywhere colour or a bitmap won't do |
| `mark/loomwright-studio-mark-white.svg` (+ PNGs) | One colour, white, on dark grounds, photographs or an `accent` fill |
| `tile/loomwright-studio-icon-{size}.png` | The app-icon tile (Dock and Finder), `app/build/icon.png` resized. Use it where an app icon is expected, such as a download button or a listing |

Every PNG comes at 16, 32, 48, 64, 128, 256, 512 and 1024 px, on a transparent ground.

Why the colour mark is a bitmap: it is a lit render, and that is what keeps it clear at every size. The icon's band is a solid lit body, and its 16 threads only shade it. A first vector attempt drew those threads as separate hairlines on an empty band. At 150–250 px each line was under a pixel wide on a 1.5–2.5 px pitch, and the lines aliased into moiré. The vector mark is therefore the solid band, in one colour.

**Clear space:** keep a quarter of the mark's height clear on every side. **Minimum size:** 16 px on screen, 6 mm in print. At 16–24 px, prefer the one-colour mark when the ground is busy.

## The name and the lockup

There is no wordmark. The name is set in plain type: **SF Pro** (the macOS system sans, `-apple-system`), tracking −0.02em, sentence case. "Loomwright" is weight 600 in `ink`; "Studio" is weight 400 in `ink-secondary`, or in `accent-hover` on the night ground. It is always the full name, "Loomwright Studio". "Loomwright" alone is the toolkit and "Wright" is the lead agent, so never shorten the app's name to either (D14).

| File | Use |
|---|---|
| `lockup/loomwright-studio-lockup-on-light.png` | Mark beside the name on a light ground, 2× pixels, transparent, clear space included |
| `lockup/loomwright-studio-lockup-on-dark.png` | The same on a dark ground |

The lockup is measured from the mark's height **M**. The name sits at type size 0.42 M, centred on the mark, with a gap of 0.28 M between them. Clear space is 0.5 M on every side. The minimum is M = 32 px, which keeps the name at 13 px, the app's `body` size. Below that, use the mark alone. The name may break after "Loomwright" when stacked (as on the social card), but it is never set in another face, outlined or put in all caps.

SF Pro isn't available as a web font outside Apple platforms, so use the PNG lockups there. Apple's SF Pro licence covers interface mock-ups for Apple platforms. Whether it also covers marketing images that show the name is an open owner question (`docs/OPEN_QUESTIONS.md`).

## Type

The system sans (SF Pro) for everything, through `-apple-system`; the mono (SF Mono) only for code. Headlines use the name's two weights and tracking −0.02em. Supporting lines are weight 400 in `ink-secondary`, or `accent-hover` on the night ground. Sentence case everywhere, with no exclamation marks and no emoji. Running text stays under 65 characters a line.

## Do and don't

- **Do** use only the files here. **Don't** recolour the mark outside its two colourways and the ink and white one-colour versions, and don't put it in a crew or semantic colour.
- **Don't** add effects: no added shadows, glows, outlines, bevels or gradients. The light on the colour mark is the icon's own render and stays as rendered.
- **Don't** rotate, stretch, mirror or redraw the mark, or trace the PNG into a vector by hand. Re-run the script instead.
- **Don't** make anything that resembles Claude Code's marks or Anthropic's. No orange-on-cream, no asterisk or burst shapes, no "Claude Code" wording. The only attribution allowed is the plain-text line "Wright, powered by Claude".
- **Wright is never the logo.** Wright is the lead agent, and its avatar (the crowned whale) appears only where Wright speaks or acts. It is never the product's mark, favicon or app icon. The same goes for every crew avatar.
- **Don't** set the name in a wordmark or a custom face, shorten it, or lock up any other words with the mark.
- **Don't** put the colour mark on a mid-tone or busy ground where it drops below 3:1. Use the ink or white one-colour version instead.
